Implement row-wise argmax over a matrix of 32-bit floating point logits, the core of greedy decoding in language models. Given logits of shape B × V (batch size by vocabulary size), write to output[b] the column index of the largest value in row b. If several columns share the maximum value, return the smallest such index.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The final result must be stored in output as 32-bit integers

Example:

Input (B = 2, V = 4): \[ \text{logits} = \begin{bmatrix} 1.0 & 3.0 & 2.0 & -1.0 \\ -2.0 & -0.5 & -0.5 & -3.0 \end{bmatrix} \] Output: \[ \text{output} = \begin{bmatrix} 1 & 1 \end{bmatrix} \] In the second row, columns 1 and 2 tie at -0.5, so the smaller index 1 is returned.

Constraints

  • 1 ≤ B ≤ 1,024
  • 1 ≤ V ≤ 262,144
  • Logits are finite 32-bit floating point numbers (no NaN)
  • Performance is measured with B = 256, V = 128,000
