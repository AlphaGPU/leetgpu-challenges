Implement a program that finds the maximum sum over all contiguous window_size × window_size subarrays of a square matrix. You are given a matrix input of shape N × N consisting of 32-bit signed integers, and an integer window_size. There are (N - window_size + 1) × (N - window_size + 1) such subarrays; write the largest of their sums to output[0].

Implementation Requirements

  • Use only native features (external libraries are not permitted)
  • The solve function signature must remain unchanged
  • The final result must be stored in the output variable

Example 1:

Input:  input = [[1, 2, 3],
                 [4, 5, 1],
                 [5, 1, 7]]
        window_size = 2
Output: output = 15

Example 2:

Input:  input = [[-1, -2, -3],
                 [-4, -5, -1],
                 [-5, -1, -7]]
        window_size = 2
Output: output = -11

Constraints

  • 1 ≤ N ≤ 5,000
  • -10 ≤ input[i][j] ≤ 10
  • 1 ≤ window_size ≤ N
  • input and output are 32-bit signed integer tensors; output has exactly one element
  • Performance is measured with N = 5,000, window_size = 2,500
