Transpose a row-major matrix input of shape rows × cols into output of shape cols × rows, so that output[j][i] = input[i][j]. All values are 32-bit floating point numbers.

Your task: make it faster. The starter code is a deliberately slow but correct CUDA kernel. Find the bottleneck, fix it, and reach at least a 2× speedup over the starter kernel on the performance test (measured on the same GPU). Your solution must still pass every correctness test.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The result must be stored in output (row-major, cols × rows)
  • The target is 2× the runtime of the provided CUDA starter kernel on the performance test

Example:

Input (rows = 2, cols = 3): \[ \text{input} = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{bmatrix} \] Output: \[ \text{output} = \begin{bmatrix} 1 & 4 \\ 2 & 5 \\ 3 & 6 \end{bmatrix} \]

Constraints

  • 1 ≤ rows, cols ≤ 8,192
  • Input values are in the range [-10, 10]
  • Target speedup: 2× over the starter kernel
  • Performance is measured with rows = 8,192, cols = 8,192
