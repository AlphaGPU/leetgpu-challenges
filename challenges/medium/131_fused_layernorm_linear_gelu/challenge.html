Implement the first half of a transformer MLP block as a single fused operation: layer normalization of each row of x (M × K), followed by a linear projection with W (K × N) and bias, followed by the exact (erf-based) GELU activation. All tensors are 32-bit floats.

\[ \hat{x}_{i} = \frac{x_{i} - \mu_i}{\sqrt{\sigma_i^2 + \varepsilon}} \odot \gamma + \beta, \qquad h_i = \hat{x}_i W + \text{bias}, \qquad y_i = \tfrac{1}{2}\, h_i \Big(1 + \text{erf}\big(h_i / \sqrt{2}\big)\Big) \]

where \(\mu_i\) and \(\sigma_i^2\) are the mean and (biased, divide-by-K) variance of row i. A fast solution computes the row statistics once and applies the normalization while loading x tiles into the GEMM, with bias and GELU in the epilogue, so neither the normalized activations nor the pre-activation are written to memory.

Implementation Requirements

  • Do not change the function signature.
  • Do not use external libraries beyond what is available in the starter.
  • Write the result to y.
  • Use the exact erf-based GELU, not the tanh approximation.

Example 1:

Input: M = 2, K = 2, N = 2, eps = 1e-5, \(\gamma = [1, 1]\), \(\beta = [0, 0]\), \(\text{bias} = [0, 1]\) \[ x = \begin{bmatrix} 1 & 3 \\ 2 & 2 \end{bmatrix}, \quad W = \begin{bmatrix} 1 & -1 \\ 0 & 2 \end{bmatrix} \] Normalized rows are \([-1, 1]\) and \([0, 0]\), so \[ h = \begin{bmatrix} -1 & 4 \\ 0 & 1 \end{bmatrix} \] Output: \[ y = \begin{bmatrix} -0.1587 & 3.9999 \\ 0.0 & 0.8413 \end{bmatrix} \]

Constraints

  • 1 ≤ M ≤ 8,192
  • 1 ≤ K, N ≤ 8,192
  • 0 < eps ≤ 1
  • Input values may carry a large common offset (e.g. around -1,000)
  • Performance is measured with M = 4,096, K = 4,096, N = 4,096
