Implement shared-prefix (cascade) attention, used when many sequences in a batch share the same prompt prefix (e.g. a long system prompt or few-shot examples). All batch_size sequences share one cached key/value prefix of prefix_len tokens, stored only once, and each sequence also has its own suffix_len suffix tokens. Each query token attends to every prefix token and causally to its own sequence's suffix tokens. All tensors are float32. A naive kernel re-reads the shared prefix once per sequence. A fast kernel reads it once for the whole batch and merges the prefix and suffix softmax partial results.

For sequence \(b\), head \(h\) and suffix query \(i\): \[ \text{output}[b,h,i] = \operatorname{softmax}\!\left(\frac{q\,[K_{\text{prefix}}[h];\;K_{\text{suffix}}[b,h,0..i]]^\top}{\sqrt{d}}\right)[V_{\text{prefix}}[h];\;V_{\text{suffix}}[b,h,0..i]] \]

Implementation Requirements

  • Implement solve(Q, K_prefix, V_prefix, K_suffix, V_suffix, output, batch_size, num_heads, prefix_len, suffix_len, head_dim).
  • Do not change the function signature or use external libraries beyond the standard GPU frameworks.
  • Write the result into output.
  • Shapes (row-major, contiguous): Q, K_suffix, V_suffix, output are (batch_size, num_heads, suffix_len, head_dim); K_prefix, V_prefix are (num_heads, prefix_len, head_dim) and are shared by every sequence.
  • Use scale 1 / sqrt(head_dim). Suffix query i sees all prefix keys and suffix keys 0..i (inclusive) of its own sequence only; it never sees other sequences' suffixes.
  • prefix_len may be 0, in which case this is plain causal attention over the suffix.

Example

batch_size = 2, num_heads = 1, prefix_len = 2, suffix_len = 2, head_dim = 2 (head dimension omitted below).

\(K_{\text{prefix}} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\), \(V_{\text{prefix}} = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}\)

Sequence 0: \(Q = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\), \(K_{\text{suffix}} = \begin{bmatrix} 1 & 1 \\ 0 & 0 \end{bmatrix}\), \(V_{\text{suffix}} = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}\)

Sequence 1: \(Q = \begin{bmatrix} 1 & 1 \\ 0 & 0 \end{bmatrix}\), \(K_{\text{suffix}} = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}\), \(V_{\text{suffix}} = \begin{bmatrix} -1 & -2 \\ 0 & 0 \end{bmatrix}\)

Output (rounded to 4 decimals):
Sequence 0: \(\begin{bmatrix} 3.0000 & 4.0000 \\ 4.0000 & 5.0000 \end{bmatrix}\), Sequence 1: \(\begin{bmatrix} 1.0000 & 1.3333 \\ 0.7500 & 1.0000 \end{bmatrix}\)

Constraints

  • 1 ≤ batch_size ≤ 64
  • 1 ≤ num_heads ≤ 64
  • 0 ≤ prefix_len ≤ 8,192
  • 1 ≤ suffix_len ≤ 1,024
  • 1 ≤ head_dim ≤ 128
  • All values are float32; tolerance is 1e-4 absolute and relative
  • Performance is measured with batch_size = 16, num_heads = 32, prefix_len = 4,096, suffix_len = 256, head_dim = 128
