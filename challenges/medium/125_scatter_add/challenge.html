Implement a row-wise scatter-add (the operation behind torch.index_add_, used to combine Mixture-of-Experts outputs and to aggregate messages in graph neural networks). Given a source matrix src of shape N × D and an integer vector index of length N, add each source row i into row index[i] of an M × D output matrix that starts at zero: \[ \text{output}[m, d] = \sum_{i \,:\, \text{index}[i] = m} \text{src}[i, d] \] All values are 32-bit floating point numbers; index holds 32-bit integers.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The final result must be stored in output; its initial contents are undefined, so every row must be written (rows no source row maps to are 0)

Example:

Input (N = 4, D = 2, M = 3): \[ \text{src} = \begin{bmatrix} 1 & 2 \\ 3 & 4 \\ 5 & 6 \\ 7 & 8 \end{bmatrix}, \quad \text{index} = \begin{bmatrix} 0 & 2 & 0 & 1 \end{bmatrix} \] Output: \[ \text{output} = \begin{bmatrix} 6 & 8 \\ 7 & 8 \\ 3 & 4 \end{bmatrix} \]

Constraints

  • 1 ≤ N ≤ 2,000,000
  • 1 ≤ D ≤ 1,024
  • 1 ≤ M ≤ 1,000,000
  • 0 ≤ index[i] < M
  • Source values are in the range [-10, 10]
  • Performance is measured with N = 1,000,000, D = 128, M = 50,000
