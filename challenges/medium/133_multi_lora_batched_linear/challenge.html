Implement the batched multi-adapter LoRA projection used by multi-tenant LLM servers (Punica / S-LoRA, vLLM multi-LoRA). A batch of T tokens x (T × K) shares one base weight W (K × N), but each token may belong to a different fine-tuned adapter selected from a pool of L low-rank adapters A (L × K × R) and B (L × R × N). With a = adapter_ids[t]:

\[ y_t = x_t W + \begin{cases} \text{scale} \cdot (x_t A_a) B_a & a \ge 0 \\ 0 & a = -1 \end{cases} \]

Tokens are not grouped by adapter. All tensors are 32-bit floats except adapter_ids, which is 32-bit integer.

Implementation Requirements

  • Do not change the function signature.
  • Do not use external libraries beyond what is available in the starter.
  • Write the result to y (shape T × N).
  • Tokens with adapter_ids[t] = -1 use only the base weight.

Example 1:

Input: T = 3, K = 2, N = 2, R = 1, L = 2, scale = 0.5, adapter_ids = [0, 1, -1] \[ x = \begin{bmatrix} 1 & 2 \\ 3 & 4 \\ 1 & 1 \end{bmatrix}, \quad W = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad A_0 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \quad A_1 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \quad B_0 = \begin{bmatrix} 1 & 1 \end{bmatrix}, \quad B_1 = \begin{bmatrix} 1 & -1 \end{bmatrix} \] Output: \[ y = \begin{bmatrix} 1.5 & 2.5 \\ 5.0 & 2.0 \\ 1.0 & 1.0 \end{bmatrix} \]

Constraints

  • 1 ≤ T ≤ 4,096
  • 1 ≤ K, N ≤ 8,192
  • 1 ≤ R ≤ 64
  • 1 ≤ L ≤ 64
  • -1 ≤ adapter_ids[t] < L
  • Performance is measured with T = 1,024, K = 4,096, N = 4,096, R = 16, L = 8
