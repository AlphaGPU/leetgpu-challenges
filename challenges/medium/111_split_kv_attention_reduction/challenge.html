When decoding a token against a long KV cache, Flash-Decoding splits the KV cache into num_splits chunks and computes a partial attention output on each chunk in parallel. Each partial output partial_out[s] is the softmax of that chunk's scores applied to that chunk's values, and each partial_lse[s] is the log-sum-exp of the chunk's scores. This kernel merges the per-chunk results into the final attention output using the log-sum-exp trick, so no chunk's contribution overflows when scores span very different magnitudes.

For each head \(h\) and each embedding dimension \(d\), given the split log-sum-exps \(\ell_{s,h} = \text{partial\_lse}[s, h]\) and partial outputs \(o_{s,h,d} = \text{partial\_out}[s, h, d]\), let \[ m_h = \max_{s} \ell_{s,h}, \qquad w_{s,h} = \exp\!\bigl(\ell_{s,h} - m_h\bigr). \] The merged attention output is the per-split-weighted average \[ \text{output}[h, d] \;=\; \frac{\sum_{s=0}^{S-1} w_{s,h} \cdot o_{s,h,d}}{\sum_{s=0}^{S-1} w_{s,h}}. \]

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • partial_out has shape (num_splits, num_heads, head_dim) with float32 values
  • partial_lse has shape (num_splits, num_heads) with float32 values
  • Subtract \(m_h\) before exponentiating to keep the merge numerically stable
  • The final result must be stored in the output tensor with shape (num_heads, head_dim)

Example 1:

With num_splits = 2, num_heads = 2, head_dim = 2, \[ \text{partial\_out} = \begin{bmatrix} \begin{bmatrix} 1 & 2 \\ 4 & 0 \end{bmatrix} \\[6pt] \begin{bmatrix} 3 & 4 \\ 0 & 8 \end{bmatrix} \end{bmatrix}, \qquad \text{partial\_lse} = \begin{bmatrix} 0 & \ln 3 \\ 0 & 0 \end{bmatrix} \] the two heads merge differently. Head 0 has equal log-sum-exps, so the weights are \(\tfrac{1}{2},\tfrac{1}{2}\); head 1 has log-sum-exps of \(\ln 3\) and \(0\), so the weights are \(\tfrac{3}{4},\tfrac{1}{4}\). The result is \[ \text{output} = \begin{bmatrix} 2 & 3 \\ 3 & 2 \end{bmatrix}. \]

Constraints

  • 1 ≤ num_splits ≤ 256
  • 1 ≤ num_heads ≤ 128
  • 1 ≤ head_dim ≤ 256
  • All tensors are float32
  • Performance is measured with num_splits = 128, num_heads = 64, head_dim = 128
