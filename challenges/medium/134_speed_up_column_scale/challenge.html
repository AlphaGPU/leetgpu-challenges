Apply a per-column affine transform to a row-major matrix input of shape M × N: output[i][j] = input[i][j] * gamma[j] + beta[j]. All values are 32-bit floating point numbers.

Your task: make it faster. The starter code is a deliberately slow but correct CUDA kernel. Find the bottleneck, fix it, and reach at least a 4.7× speedup over the starter kernel on the performance test (measured on the same GPU). Your solution must still pass every correctness test.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The result must be stored in output (row-major, M × N)
  • The target is 4.7× the runtime of the provided CUDA starter kernel on the performance test

Example:

Input (M = 2, N = 3): \[ \text{input} = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{bmatrix}, \quad \text{gamma} = \begin{bmatrix} 2 & 0.5 & -1 \end{bmatrix}, \quad \text{beta} = \begin{bmatrix} 1 & 0 & 3 \end{bmatrix} \] Output: \[ \text{output} = \begin{bmatrix} 3 & 1 & 0 \\ 9 & 2.5 & -3 \end{bmatrix} \]

Constraints

  • 1 ≤ M, N ≤ 8,192
  • Input values are in the range [-100, 100]; gamma and beta are in [-2, 2]
  • Target speedup: 4.7× over the starter kernel
  • Performance is measured with M = 8,192, N = 8,192
