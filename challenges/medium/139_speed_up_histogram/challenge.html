Count how many elements of the integer array input (length N) fall into each of num_bins bins: histogram[b] is the number of indices i with input[i] = b. Values and counts are 32-bit integers.

Your task: make it faster. The starter code is a deliberately slow but correct CUDA kernel. Find the bottleneck, fix it, and reach at least a 4× speedup over the starter kernel on the performance test (measured on the same GPU). Your solution must still pass every correctness test.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The result must be stored in histogram; its initial contents are undefined, so every bin must be written
  • The target is 4× the runtime of the provided CUDA starter kernel on the performance test

Example:

Input:  input = [0, 1, 2, 1, 0, 1], N = 6, num_bins = 4
Output: histogram = [2, 3, 1, 0]

Constraints

  • 1 ≤ N ≤ 100,000,000
  • 1 ≤ num_bins ≤ 1,024
  • 0 ≤ input[i] < num_bins
  • Target speedup: 4× over the starter kernel
  • Performance is measured with N = 50,000,000, num_bins = 32
