Compute the sum of each row of a row-major matrix input of shape M × N: output[i] = input[i][0] + ... + input[i][N-1]. All values are 32-bit floating point numbers; any summation order is accepted within tolerance.

Your task: make it faster. The starter code is a deliberately slow but correct CUDA kernel. Find the bottleneck, fix it, and reach at least a 3.8× speedup over the starter kernel on the performance test (measured on the same GPU). Your solution must still pass every correctness test.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The result must be stored in output (length M)
  • The target is 3.8× the runtime of the provided CUDA starter kernel on the performance test

Example:

Input (M = 2, N = 4): \[ \text{input} = \begin{bmatrix} 1 & 2 & 3 & 4 \\ -1 & 0.5 & 2.5 & -3 \end{bmatrix} \] Output: \[ \text{output} = \begin{bmatrix} 10 & -1 \end{bmatrix} \]

Constraints

  • 1 ≤ M ≤ 65,535
  • 1 ≤ N ≤ 8,192
  • Input values are in the range [-10, 10]
  • Target speedup: 3.8× over the starter kernel
  • Performance is measured with M = 16,384, N = 4,096
