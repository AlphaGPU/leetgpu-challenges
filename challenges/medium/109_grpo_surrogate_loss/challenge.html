Given rewards for G sampled responses to each of B prompts, compute the Group Relative Policy Optimization (GRPO) surrogate loss over S response tokens. Normalize rewards within each prompt's response group to obtain a sequence-level advantage, broadcast that advantage across the response tokens, apply the clipped policy objective, and add the non-negative reference-policy KL estimator.

At position [b, g, s], every log probability refers to the same sampled token y[b,g,s] conditioned on prompt b and its preceding response tokens.

Implementation Requirements

  • Implement solve(rewards, log_pi, log_pi_old, log_ref, output, clip_eps, beta, B, G, S) with the signature unchanged
  • Write the scalar mean loss into output[0]
  • Use only native features of the selected framework; external libraries are not permitted
  • Rewards have shape [B, G]; all log-probability tensors have shape [B, G, S]
  • Token masks and padding handling are outside the scope of this challenge; all S positions participate in the reduction
  • Rewards, log_pi_old, and log_ref are fixed precomputed inputs; do not differentiate through them

Loss Calculation

Normalize rewards independently within each prompt group using the population standard deviation:

\[ \mu_b = \frac{1}{G}\sum_{g=0}^{G-1} R_{b,g}, \qquad \sigma_b = \sqrt{\frac{1}{G}\sum_{g=0}^{G-1}(R_{b,g}-\mu_b)^2} \] \[ A_{b,g} = \frac{R_{b,g}-\mu_b}{\sigma_b + 10^{-8}}, \qquad A_{b,g,s} = A_{b,g} \]

Broadcast the sequence advantage over tokens and compute the clipped policy objective:

\[ r_{b,g,s} = \exp\!\left(\text{log_pi}_{b,g,s} - \text{log_pi_old}_{b,g,s}\right) \] \[ L^{\mathrm{clip}}_{b,g,s} = \min\!\left( r_{b,g,s}A_{b,g,s}, \operatorname{clip}(r_{b,g,s},1-\text{clip_eps},1+\text{clip_eps})A_{b,g,s} \right) \]

Use the non-negative k3 reference-policy KL sample estimator. Its expectation is KL(pi || pi_ref) when tokens are sampled from the current policy.

\[ d_{b,g,s} = \text{log_ref}_{b,g,s} - \text{log_pi}_{b,g,s} \] \[ K_{b,g,s} = \exp(d_{b,g,s}) - d_{b,g,s} - 1 \] \[ \text{output} = -\frac{1}{BGS}\sum_{b,g,s} \left(L^{\mathrm{clip}}_{b,g,s} - \text{beta}K_{b,g,s}\right) \]

Examples

For B = 1, G = 2, S = 2, clip_eps = 0.2, and beta = 0.01:

\[ \text{rewards} = \begin{bmatrix} 10.0 & 0.0 \end{bmatrix}, \quad \text{log_pi} = \begin{bmatrix} 0.1 & 0.2 \\ -0.5 & -0.4 \end{bmatrix} \] \[ \text{log_pi_old} = \begin{bmatrix} 0.0 & 0.0 \\ 0.0 & 0.0 \end{bmatrix}, \quad \text{log_ref} = \begin{bmatrix} 0.0 & 0.0 \\ 0.0 & 0.0 \end{bmatrix} \] \[ \text{output} \approx \begin{bmatrix} -0.17563 \end{bmatrix} \]

Constraints

  • 1 ≤ B ≤ 256
  • 2 ≤ G ≤ 32
  • 1 ≤ S ≤ 16,384
  • All tensors contain 32-bit floating point values
  • 0 ≤ clip_eps < 1 and 0 ≤ beta ≤ 1
  • Both log_pi - log_pi_old and log_ref - log_pi lie in [-16, 16], so every exponential is finite in float32
  • Performance is measured with B = 64, G = 16, S = 4,096
