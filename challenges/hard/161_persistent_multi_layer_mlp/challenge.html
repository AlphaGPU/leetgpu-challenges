Implement a stack of L pre-norm residual SwiGLU MLP layers in one persistent megakernel. The input x has shape [M, d_model]. For each layer l = 0, …, L-1, RMS-normalize the residual stream, apply a SwiGLU feed-forward (gate, up, SiLU, element-wise product, down), and add the result back to the residual stream. All tensors are float32.

The intended approach is a single persistent kernel launch that keeps the grid alive across layers and uses grid-wide synchronization (for example cooperative groups) between layers, rather than launching a separate kernel for every layer. The judge checks numerical correctness, not the number of launches, but the problem is designed so that a persistent implementation is the natural way to hit the performance target.

Layer l uses its own RMSNorm scale and its own SwiGLU weights. There are no bias terms. Matrices are stored row-major with shape (in_dim, out_dim) (plus a leading layer axis) and are applied as z × W[l].

\[ \begin{aligned} h^{(0)} &= x \\[4pt] \tilde{h}^{(l)} &= \text{RMSNorm}\!\left(h^{(l)},\, w^{(l)}\right) \\[4pt] h^{(l+1)} &= h^{(l)} + \bigl(\text{SiLU}(\tilde{h}^{(l)}\, W_{\text{gate}}^{(l)}) \odot \tilde{h}^{(l)}\, W_{\text{up}}^{(l)}\bigr)\, W_{\text{down}}^{(l)} \\[8pt] \text{RMSNorm}(z, w) &= \frac{z}{\sqrt{\frac{1}{d}\sum_i z_i^2 + \varepsilon}} \odot w, \quad \varepsilon = 10^{-5} \\[4pt] \text{output} &= h^{(L)} \end{aligned} \]

\(\text{SiLU}(x) = x \cdot \sigma(x)\). The residual add uses the pre-norm hidden state h^{(l)}, not the normalized values.

Implementation Requirements

  • Use only native features (external libraries are not permitted)
  • The solve function signature must remain unchanged
  • Store the result after all L layers in output
  • RMSNorm uses \(\varepsilon = 10^{-5}\) and has no additive bias
  • Apply layers in order 0 … L-1 with a residual add after each SwiGLU
  • All linear maps are float32 matrix multiplies with no bias

Example

With M = 2, d_model = 2, d_ffn = 2 and L = 2, layer 0 is a rank-1 SwiGLU on the first coordinate and layer 1 is the same on the second: 

x        = [[1, 0], [0, 1]]
rms_w    = [[1, 1], [1, 1]]
W_gate   = [[[1, 0], [0, 0]], [[0, 0], [0, 1]]]
W_up     = [[[1, 0], [0, 0]], [[0, 0], [0, 1]]]
W_down   = [[[1, 0], [0, 0]], [[0, 0], [0, 1]]]

output   = [[2.608823, 0.000000], [0.000000, 2.608823]]

Constraints

  • 1 ≤ M, 1 ≤ d_model, 1 ≤ d_ffn, 1 ≤ L
  • All tensors are 32-bit floating point
  • Performance is measured with M = 2,048, d_model = 1,024, d_ffn = 2,816, L = 8
