Implement the verification attention step of tree-based speculative decoding (Medusa, EAGLE, SpecInfer). A draft model proposes a tree of T candidate tokens that continue a context of P tokens whose keys and values are already in K_cache and V_cache (shape P × H × D). The target model scores every tree node in a single forward pass: node i (query Q[i], key K_tree[i], value V_tree[i]) attends to all P context tokens plus every node on its own root-to-node path, and to nothing else.

The tree is given by parents: parents[i] is the index of node i's parent, with parents[i] < i, or -1 if node i directly follows the context. Let \(\mathcal{A}(i)\) be node i together with all of its ancestors. For each head h:

\[ s_{i,j} = \frac{Q_{i,h} \cdot K_{j,h}}{\sqrt{D}}, \qquad \text{output}_{i,h} = \sum_{j \in \text{ctx} \,\cup\, \mathcal{A}(i)} \frac{e^{s_{i,j}}}{\sum_{j' \in \text{ctx} \,\cup\, \mathcal{A}(i)} e^{s_{i,j'}}} \, V_{j,h} \]

where context keys/values come from the caches and tree keys/values from K_tree/V_tree. All tensors are 32-bit floats except parents, which is 32-bit integer.

Implementation Requirements

  • Do not change the function signature.
  • Do not use external libraries beyond what is available in the starter.
  • Write the result to output (shape T × H × D).
  • The softmax must be numerically stable for large scores.

Example 1:

Input: P = 1, T = 3, H = 1, D = 2, parents = [-1, 0, 0] (node 0 follows the context; nodes 1 and 2 are siblings under node 0) \[ Q = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix}, \quad K_{\text{cache}} = \begin{bmatrix} 1 & 0 \end{bmatrix}, \quad V_{\text{cache}} = \begin{bmatrix} 1 & 2 \end{bmatrix} \] \[ K_{\text{tree}} = \begin{bmatrix} 0 & 1 \\ 1 & 1 \\ 0 & 0 \end{bmatrix}, \quad V_{\text{tree}} = \begin{bmatrix} 3 & 0 \\ 0 & 3 \\ 2 & 2 \end{bmatrix} \] Node 0 attends to {context, 0}; node 1 to {context, 0, 1}; node 2 to {context, 0, 2}.
Output: \[ \begin{bmatrix} 1.6605 & 1.3395 \\ 1.4011 & 1.5989 \\ 2.0000 & 1.1978 \end{bmatrix} \]

Constraints

  • 1 ≤ P ≤ 16,384
  • 1 ≤ T ≤ 128
  • 1 ≤ H ≤ 64
  • 1 ≤ D ≤ 256
  • -1 ≤ parents[i] < i
  • Input values are in [-6, 6]
  • Performance is measured with P = 8,192, T = 64, H = 32, D = 128
