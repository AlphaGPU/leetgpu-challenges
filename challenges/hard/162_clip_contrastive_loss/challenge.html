Compute the symmetric InfoNCE loss used to train CLIP-style image–text models. Given a batch of N paired embeddings image_embeds and text_embeds, each of shape N × D (row i of both is a matching pair), L2-normalize every row, form the scaled cosine-similarity matrix, and average the cross-entropy of classifying each image's matching text (softmax over each row) and each text's matching image (softmax over each column). All tensors are 32-bit floats; write the scalar loss to loss[0].

\[ \hat{x}_i = \frac{x_i}{\lVert x_i \rVert_2}, \quad \hat{y}_j = \frac{y_j}{\lVert y_j \rVert_2}, \quad S_{i,j} = \text{logit_scale} \cdot \hat{x}_i \cdot \hat{y}_j \] \[ \text{loss} = \frac{1}{2}\left( \frac{1}{N}\sum_{i=0}^{N-1}\Big(\log\sum_{j=0}^{N-1} e^{S_{i,j}} - S_{i,i}\Big) + \frac{1}{N}\sum_{j=0}^{N-1}\Big(\log\sum_{i=0}^{N-1} e^{S_{i,j}} - S_{j,j}\Big) \right) \]

where x = image_embeds and y = text_embeds. The N × N logit matrix is much larger than the inputs, so a fast solution computes each tile of S once and folds it into running log-sum-exp statistics for both its rows and its columns instead of materializing S.

Implementation Requirements

  • Do not change the function signature.
  • Do not use external libraries beyond what is available in the starter.
  • Write the scalar loss to loss[0].
  • The computation must be numerically stable for logits up to logit_scale (subtract the running maximum).

Example 1:

Input (N = 2, D = 2, logit_scale = 2.0): \[ \text{image_embeds} = \begin{bmatrix} 1 & 0 \\ 0 & 2 \end{bmatrix}, \quad \text{text_embeds} = \begin{bmatrix} 3 & 4 \\ 0 & -1 \end{bmatrix} \] Normalized rows and logits: \[ \hat{x} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad \hat{y} = \begin{bmatrix} 0.6 & 0.8 \\ 0 & -1 \end{bmatrix}, \quad S = \begin{bmatrix} 1.2 & 0 \\ 1.6 & -2 \end{bmatrix} \] Row (image → text) losses: \(\log(e^{1.2} + e^{0}) - 1.2 \approx 0.2633\) and \(\log(e^{1.6} + e^{-2}) + 2 \approx 3.6270\), mean 1.9451.
Column (text → image) losses: \(\log(e^{1.2} + e^{1.6}) - 1.2 \approx 0.9130\) and \(\log(e^{0} + e^{-2}) + 2 \approx 2.1269\), mean 1.5200.
Output: loss = 0.5 × (1.9451 + 1.5200) = 1.7325

Constraints

  • 1 ≤ N ≤ 32,768
  • 1 ≤ D ≤ 1,024
  • 0 ≤ logit_scale ≤ 100
  • Every row of image_embeds and text_embeds has a nonzero L2 norm
  • Rows may have arbitrary magnitudes; only their directions affect the loss
  • Performance is measured with N = 16,384, D = 512, logit_scale = 100.0
