Implement the forward pass of causal stick-breaking attention (Tan et al., “Scaling Stick-Breaking Attention”, ICLR 2025), a softmax-free replacement for attention that needs no positional encoding. Each query breaks a unit-length stick, starting from the most recent earlier token and moving back in time: token j takes the fraction σ(z) of whatever is left of the stick, so recent tokens with large logits soak up the attention and older tokens only get what remains. All tensors are float32; the H query heads share H_KV key/value heads (grouped-query attention).

Implementation Requirements

Implement solve(q, k, v, output, B, H, H_KV, S, D):

  • q: shape (B, H, S, D), float32, the queries
  • k, v: shape (B, H_KV, S, D), float32, the keys and values
  • output: shape (B, H, S, D), float32

Query head h uses key/value head \(g = \lfloor h / (H / H_{KV}) \rfloor\). For sequence b, head h and query position i, with \(\sigma(x) = 1 / (1 + e^{-x})\): \[ z_{i,j} = \frac{q_{b,h,i} \cdot k_{b,g,j}}{\sqrt{D}}, \qquad A_{i,j} = \sigma(z_{i,j}) \prod_{m=j+1}^{i-1} \big(1 - \sigma(z_{i,m})\big) \quad (0 \le j < i) \] \[ \text{output}_{b,h,i} = \sum_{j=0}^{i-1} A_{i,j}\, v_{b,g,j} \] Only keys strictly before the query are attended (the diagonal is excluded), so output at position 0 is all zeros.   • Use only native features of the framework you choose (no external libraries); keep the function signature unchanged
  • Write the result into output; the inputs must not be modified
  • The weights must be computed stably for logits in the hundreds (e.g. \(\log(1 + e^{z})\) overflows float32 for \(z > 88\))

Example

Input: B = 1, H = 1, H_KV = 1, S = 4, D = 2. Rows are positions: \[ q = \begin{bmatrix} 0 & 0 \\ 2 & 0 \\ 0 & 2 \\ 2 & 2 \end{bmatrix}, \quad k = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ -1 & 0 \\ 0 & 0 \end{bmatrix}, \quad v = \begin{bmatrix} 1 & 2 \\ 3 & 4 \\ 5 & 6 \\ 7 & 8 \end{bmatrix} \] Every logit is \(0\) or \(\pm\sqrt{2}\), and \(\sigma(\sqrt{2}) = 0.8044297\), \(\sigma(0) = 0.5\), \(\sigma(-\sqrt{2}) = 0.1955703\). Position 0 has no earlier key, so its output is \([0, 0]\). Position 1 sees key 0 with \(z = \sqrt{2}\): \(A_{1,0} = 0.8044297\). Position 2 has \(z = [0, \sqrt{2}]\): \(A_{2,1} = 0.8044297\) and \(A_{2,0} = 0.5 \cdot (1 - 0.8044297) = 0.0977852\). Position 3 has \(z = [\sqrt{2}, \sqrt{2}, -\sqrt{2}]\): \(A_{3,2} = 0.1955703\), \(A_{3,1} = 0.8044297 \cdot 0.8044297 = 0.6471071\) and \(A_{3,0} = 0.8044297 \cdot 0.1955703 \cdot 0.8044297 = 0.1265549\). The output is \[ \text{output} = \begin{bmatrix} 0 & 0 \\ 0.8044297 & 1.6088594 \\ 2.5110742 & 3.4132890 \\ 3.0457279 & 4.0149602 \end{bmatrix} \]

Constraints

  • 1 ≤ B ≤ 8; 1 ≤ S ≤ 8,192; 1 ≤ D ≤ 128
  • 1 ≤ H_KV ≤ H ≤ 32, and H is a multiple of H_KV
  • q values lie in [-150, 150]; k and v values lie in [-1, 1]
  • Performance is measured with B = 2, H = 16, H_KV = 4, S = 8,192, D = 128
