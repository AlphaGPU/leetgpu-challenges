Implement a fused single-token decoder layer — the Llama-style pre-norm block that runs at every decode step. A batch of B sequences each contributes one new hidden state (row of x, shape [B, d_model]). The kernel must RMS-normalize that token, project Q, K and V, apply rotary embeddings, write the new key and value into the KV cache at positions[b], attend over the valid prefix of the cache, apply the output projection and residual, then run a pre-norm SwiGLU MLP and residual. All tensors are float32 except positions, which is int32.

The intended approach is a megakernel: a single persistent kernel launch that fuses the whole decode step, rather than a chain of separate kernels for RMSNorm, QKV, attention, and the MLP. The judge checks numerical correctness, not the number of launches, but the problem is designed so that a fused implementation is the natural way to hit the performance target.

The block is pre-norm and has no bias terms. d_model equals H_q × D, and H_q is divisible by H_kv (grouped-query attention). Weight matrices are stored row-major with shape (in_dim, out_dim) and are applied as x × W.

\[ \begin{aligned} x' &= x + \text{Attn}\!\left(\text{RMSNorm}_1(x),\; K_{\text{cache}},\; V_{\text{cache}},\; \text{positions}\right) \\[4pt] \text{output} &= x' + \text{FFN}\!\left(\text{RMSNorm}_2(x')\right) \end{aligned} \]

The sub-operations in detail:

\[ \begin{aligned} \text{RMSNorm}(z, w) &= \frac{z}{\sqrt{\frac{1}{d}\sum_i z_i^2 + \varepsilon}} \odot w, \quad \varepsilon = 10^{-5} \\[8pt] Q &= \text{RMSNorm}_1(x)\, W_Q \in \mathbb{R}^{B \times (H_q D)}, \quad \text{reshape to } (B, H_q, D) \\[4pt] K &= \text{RMSNorm}_1(x)\, W_K \in \mathbb{R}^{B \times (H_{kv} D)}, \quad \text{reshape to } (B, H_{kv}, D) \\[4pt] V &= \text{RMSNorm}_1(x)\, W_V \in \mathbb{R}^{B \times (H_{kv} D)}, \quad \text{reshape to } (B, H_{kv}, D) \\[8pt] \text{RoPE}(t, c, s)_j &= t_j\, c_j - t_{j+D/2}\, s_j, \qquad \text{RoPE}(t, c, s)_{j+D/2} = t_{j+D/2}\, c_j + t_j\, s_j \\[4pt] &\quad c = \text{cos_sin_cache}[p, {:}D/2],\; s = \text{cos_sin_cache}[p, {D/2:}],\; p = \text{positions}[b] \\[8pt] K_{\text{cache}}[b, h, p, :] &\leftarrow \text{RoPE}(K[b, h]), \qquad V_{\text{cache}}[b, h, p, :] \leftarrow V[b, h] \\[8pt] \text{GQA} &: \text{query head } h \text{ maps to KV head } kv = h \mathbin{//} (H_q / H_{kv}) \\[4pt] \text{head}_{b,i} &= \text{softmax}\!\left(\frac{Q_{b,i}\, K_{b,i,:}^{\top}}{\sqrt{D}} + M_b\right) V_{b,i} \\[4pt] M_b[s] &= 0 \text{ if } s \le \text{positions}[b],\ \text{else } -\infty \\[8pt] \text{Attn}(x) &= \text{Concat}(\text{heads})\; W_O \\[8pt] \text{FFN}(z) &= \bigl(\text{SiLU}(z\, W_{\text{gate}}) \odot z\, W_{\text{up}}\bigr)\; W_{\text{down}} \end{aligned} \]

Every cache slot other than positions[b] must keep the value it had on entry. The new token of sequence b may attend only to cache slots 0, …, positions[b] (inclusive of the slot just written). \(\text{SiLU}(x) = x \cdot \sigma(x)\). RoPE is applied to Q and K only, never to V.

Implementation Requirements

  • Use only native features (external libraries are not permitted)
  • The solve function signature must remain unchanged
  • Store the layer output in output and write the new key and value into K_cache and V_cache at positions[b]
  • Leave every other cache slot unchanged
  • RMSNorm uses \(\varepsilon = 10^{-5}\) and has no additive bias
  • Map query head h to KV head h // (H_q / H_kv)
  • cos_sin_cache has shape [S_max, D]: the first D/2 entries of row p are cosines, the last D/2 are sines
  • All linear maps are float32 matrix multiplies with no bias
  • Read every weight from the packed weights buffer described below

Weight Layout

All parameters are packed into a single contiguous weights buffer in the order below. Two-dimensional matrices are stored row-major with shape (in_dim, out_dim) and applied as z × W. There are no bias terms. Because d_model = H_q × D, W_Q and W_O are both d_model × d_model.

Parameter Shape Size Offset
\(w_1\) (RMSNorm 1 scale) (d_model,) d_model 0
\(W_Q\) (d_model, d_model) d_model² d_model
\(W_K\) (d_model, H_kv × D) d_model × H_kv × D d_model + d_model²
\(W_V\) (d_model, H_kv × D) d_model × H_kv × D d_model + d_model² + d_model × H_kv × D
\(W_O\) (d_model, d_model) d_model² d_model + d_model² + 2 × d_model × H_kv × D
\(w_2\) (RMSNorm 2 scale) (d_model,) d_model d_model + 2 × d_model² + 2 × d_model × H_kv × D
\(W_{\text{gate}}\) (d_model, d_ffn) d_model × d_ffn 2 × d_model + 2 × d_model² + 2 × d_model × H_kv × D
\(W_{\text{up}}\) (d_model, d_ffn) d_model × d_ffn (same as gate) + d_model × d_ffn
\(W_{\text{down}}\) (d_ffn, d_model) d_ffn × d_model (same as up) + d_model × d_ffn

Example

With B = 1, d_model = 4, H_q = 2, H_kv = 1, D = 2, d_ffn = 4, S_max = 2 and positions = [1]: 

x               = [[1, 0, 0, 0]]
weights         = packed 104-vector (layout above; offsets for this example:
                  w1@0, W_Q@4, W_K@20, W_V@28, W_O@36, w2@52,
                  W_gate@56, W_up@72, W_down@88)
                  w1 = w2 = [1, 1, 1, 1]
                  W_Q = W_O = I_4
                  W_K = [[1, 0], [0, 1], [0, 0], [0, 0]]
                  W_V = [[1, 0], [0, 0], [0, 1], [0, 0]]
                  W_gate = W_up = W_down = e_00  (1 at [0, 0], else 0)
cos_sin_cache   = [[1, 0], [0, 1]]     # identity RoPE at pos 0, 90-degree at pos 1
K_cache (in)    = [[[[2, 0], [9, 9]]]]
V_cache (in)    = [[[[0, 1], [8, 8]]]]

output          = [[5.899476, 0.055813, 0.999980, 0.500000]]
K_cache (out)   = [[[[2, 0], [0, 1.999960]]]]   # slot 0 unchanged; slot 1 written
V_cache (out)   = [[[[0, 1], [1.999960, 0]]]]

Constraints

  • d_model = H_q × D, and H_q is divisible by H_kv
  • 1 ≤ B, 1 ≤ H_kv ≤ H_q, 2 ≤ D with D even, 1 ≤ d_ffn, 1 ≤ S_max
  • 0 ≤ positions[b] < S_max
  • All floating-point tensors are 32-bit; positions is 32-bit integer
  • Performance is measured with B = 32, d_model = 2,048, H_q = 16, H_kv = 4, D = 128, d_ffn = 5,632, S_max = 2,048
