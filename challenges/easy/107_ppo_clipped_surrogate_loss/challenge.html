Given precomputed advantages and log probabilities from the current policy, previous policy, and reference policy, compute the scalar PPO clipped surrogate loss. The operation combines a clipped policy ratio with a KL penalty and reduces the result across a batch of sequences.

Implementation Requirements

  • Implement solve(advantages, log_pi, log_pi_old, log_ref, output, clip_eps, beta, B, S) with the signature unchanged
  • Write the single scalar result into the preallocated output tensor
  • Use only native features of the selected framework; external libraries are not permitted
  • All input tensors have shape [B, S] and the output has shape [1]

Examples

For B = 1, S = 4, clip_eps = 0.2, and beta = 0.01:

\[ \text{advantages} = \begin{bmatrix} 1.0 & -2.0 & 3.0 & -4.0 \end{bmatrix}, \quad \text{log\_pi} = \begin{bmatrix} \log(1.3) & \log(0.7) & \log(1.1) & \log(0.8) \end{bmatrix} \] \[ \text{log\_pi\_old} = \begin{bmatrix} 0.0 & 0.0 & 0.0 & 0.0 \end{bmatrix}, \quad \text{log\_ref} = \begin{bmatrix} 0.1 & -0.2 & 0.05 & -0.1 \end{bmatrix} \] \[ \text{output} = \begin{bmatrix} 0.07518 \end{bmatrix} \]

Constraints

  • 1 ≤ B ≤ 256
  • 1 ≤ S ≤ 16,384
  • All tensors contain 32-bit floating point values
  • 0 ≤ clip_eps < 1 and 0 ≤ beta ≤ 1
  • Policy log probabilities are finite, so the policy ratio is well-defined
  • Performance is measured with B = 128, S = 2,048
