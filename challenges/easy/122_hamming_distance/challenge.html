Implement a program that computes the Hamming distance between a 32-bit query code and each of N 32-bit codes in the array codes. The Hamming distance is the number of bit positions at which the two codes differ, so each result is between 0 and 32. This is the scoring step of binary-hash nearest-neighbor search, used by hash-based sparse attention to rank keys cheaply.

Implementation Requirements

  • External libraries are not permitted
  • The solve function signature must remain unchanged
  • The final result must be stored in array output

Example 1:

Input:  codes = [5, 0, 7, -1], query = 5
Output: output = [0, 2, 1, 30]

Example 2:

Input:  codes = [0, 1, 11, -1], query = 0
Output: output = [0, 1, 3, 32]

Constraints

  • 1 ≤ N ≤ 100,000,000
  • codes[i] and query are signed 32-bit integers; all 32 bits count, including the sign bit
  • Performance is measured with N = 25,000,000
